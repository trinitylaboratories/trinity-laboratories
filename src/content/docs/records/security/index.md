## Interpretation rule

An information level such as **TL-4** is not a facility badge. A physical level such as **S-4 / C-R-X** is not permission to read compartmented records.

- Clearance establishes eligibility.
- Compartment authorization establishes access.
- Need-to-know establishes permission.
- Physical security authority governs location and interaction.
